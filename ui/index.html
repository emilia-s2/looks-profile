Gerenciar perfis e retratos

Opcional · 64 × 64 pixels

Todos os perfis salvos entram no catálogo ao abrir o TERA. Em Customize → Presets, clique em Preset 1, 2 etc. ao lado do aleatório; passe o mouse para ver o nome. Só aparecem perfis da mesma raça e gênero. Para incluir perfis ou retratos novos no catálogo, reabra somente o TERA com Toolbox iniciado.

Guardar uma aparência

Salva uma nova cópia com os dados de aparência. Reabra somente o TERA, mantendo o Toolbox iniciado, para o novo perfil aparecer em Customize → Presets.

Escolha ou cole uma captura feita ao salvar este personagem. Você enquadra o rosto; o ícone será salvo junto do novo perfil.

Para salvar seu personagem, entre no mundo. Outro personagem precisa estar na lista de seleção recebida pelo mod ou visível no mapa.

Presets salvos no criador

  1. Salve os perfis desejados. Abra ou reabra somente o TERA, com Toolbox iniciado.
  2. Escolha raça, gênero e classe normalmente. Entre em Customize e abra Presets.
  3. Clique nos presets salvos ao lado do aleatório. Aguarde a conclusão; depois pode ajustar ou trocar de preset.

Não precisa ativar os perfis um por um. A lista do jogo é carregada por abertura, com até 64 perfis; perfis ou retratos novos entram ao reabrir somente o TERA. Consulte o nome passando o mouse sobre o preset.

Retratos dos presets

Ao salvar, use Escolher retrato opcional para importar uma captura PNG/JPEG ou colar um print. Clique no rosto, ajuste o quadrado e confira a prévia. Para perfis existentes, selecione o perfil e use Adicionar ou trocar retrato. Reabra somente o TERA para os ícones aparecerem no criador. Perfis sem imagem continuam com o botão de texto. O retrato é uma imagem escolhida por você, inclusive para personagens próximos.
