Guardar uma aparência

Crie um perfil novo com a aparência de um personagem. O retrato é opcional.

Retrato do novo perfil
Opcional · 64 × 64 pixels

Use uma imagem do computador ou cole uma captura da tela. Depois enquadre o rosto.

A imagem vira o ícone do preset. A aparência é copiada do personagem escolhido abaixo.

Entre no mundo com o personagem que deseja salvar.

Pode ser outro personagem seu na seleção ou um jogador visível no mapa. Digite o nome exato ou escolha uma sugestão.

Se deixar vazio, será usado o nome do personagem.

Para substituir um perfil existente, use Atualizar com meu personagem na aba Perfis salvos.

Depois de salvar, reabra somente o TERA com Toolbox iniciado. O novo perfil aparecerá em Customize → Presets, para a mesma raça e gênero.

Presets salvos no criador

  1. Salve os perfis desejados. Abra ou reabra somente o TERA, com Toolbox iniciado.
  2. Escolha raça, gênero e classe normalmente. Entre em Customize e abra Presets.
  3. Clique nos presets salvos ao lado do aleatório. Aguarde a conclusão; depois pode ajustar ou trocar de preset.

Não precisa ativar os perfis um por um. A lista do jogo é carregada por abertura, com até 64 perfis; perfis ou retratos novos entram ao reabrir somente o TERA. Consulte o nome passando o mouse sobre o preset.

Retratos dos presets

Use o quadro do retrato ou o botão Adicionar retrato para importar uma captura PNG/JPEG ou colar um print. Clique no rosto, ajuste o quadrado e confira a prévia. Para perfis existentes, selecione o perfil; se já tiver imagem, use Trocar retrato. Reabra somente o TERA para os ícones aparecerem no criador. Perfis sem imagem continuam com o botão de texto. O retrato é uma imagem escolhida por você, inclusive para personagens próximos.
